# 首次使用、设置与恢复

通用版不自动安装微信桥、不代用户扫码或保存新凭据。部署者先自行完成桥登录和精确账号/联系人配置。`serve --live` 验证服务ID、账号ID、本人username、在线认证状态，再记录当前事件头；不会导入旧聊天。

显式配置 `setup_peer` 时，只向这个白名单对象发送一次首次说明；未配置则等待各白名单对象的新文字。说明包含虚构AI角色扮演、实际模型供应商、非专业治疗、记忆/图片数据用途。不同意后保持安静。未同意及未完成设置前，不调用角色模型、不发主动消息。

状态机：

```text
new → await_consent → role → role_location → style → interaction → confirm → ready
          ↓拒绝                                           ↓完整安全词
       declined                                         settings
          ↑重新发安全词                         保存→ready / 取消→ready
任意阶段 /exitrole → exited（主动暂停）→完整安全词→重新同意
```

初次步骤：回复「同意」或 `/acceptrole`；选择注册角色完整名称；确认有来源的角色地点/时区建议，或发送 `所在地 城市 IANA时区` / `地点未知`；描述200字内风格；选「被动」或「随机 90 180」；最后「确认」。不能通过一句同意跳过角色/互动设置。未准备的角色档案会明确提示，程序不谎称已经自动研究好任意角色。

安全词配置 `settings_word`，默认 `/settings`。必须整条消息去除首尾空白后精确相等，引用、包含该短语不会触发。安全词不是密码，不授予陌生人权限；身份仍由认证微信桥和精确白名单保证。不要将API key或其他凭据用作安全词。

设置菜单支持：

* `角色 小睦`、`风格 简短而温柔`。
* `场景 与团员在练习室排练`：明确的虚构世界场景，单独保存，12小时后不再强制沿用；不写入现实用户事实。
* `随机 90 180`：最短/最长分钟，5至10080；未回复退避、共享额度照常。
* `定时 09:30 简短问候`：每日任务，最多5项；`时区 Asia/Shanghai`。
* `暂停`、`恢复`、`清空定时`；最后 `保存` 应用或 `取消`。

修改期间角色回复和主动消息暂停；草稿不会提前生效。每人独立角色、风格、场景、时区、任务和同意状态。共享API预算的日期仍按部署者配置，不能通过更换个人时区重置额度。

`/pause`、`/forget` 可在额度耗尽时本地执行。`/exitrole` 先本地撤回同意并暂停主动；无法撤回已经提交的消息或中断已经在途的网络请求。退出不会删除设置和聊天记忆；`/forget` 删除事实/近期对话，不保证擦除SQLite空闲页或系统备份。设置元数据与操作去重记录仍保留。

完成回执后才推进状态；未知发送留下pending屏障，重启不自动重复发送。正常退出/重启会恢复精确设置步骤和草稿。运营者可用 `python -m companion status --config config.local.json --live` 查看pending事件ID，然后：

```sh
python -m companion recover-setup --config config.local.json --live --event PENDING_EVENT_ID
```

恢复只查询同一认证桥上该幂等键的既有发送；严格匹配账号、目标、accepted与serverId后才推进本地状态，不再发送一次。无记录、拒绝或未知结果仍停止，不能随意清除屏障。CLI状态含私有运营元数据，不要贴到公开issue。

`python3 setup_demo.py` 可离线体验，数据在 `.setup-demo-state`，不联网不收费。当前真实微信端首次配置仍未实测。这里的主动“短信式”体验只是微信文字；没有接入真实SMS、拨号或电话。


## 角色地点与记忆隔离

角色档案可带 `location`：`name`、`timezone`、`confidence: verified`、`source`、`timezone_source`；后两个字段引用档案的 reviewed 来源ID。地点和时区均有来源才建议，不根据角色名、国籍或用户所在地推测。没有资料时询问用户；用户可显式自设。当前小睦公开档案没有已核实的城市字段，因此通用版不会自动断定东京。

首次选择或更换角色后，建议只放在草稿中；`确认地点` 或手动设置后还需最终保存。`地点未知` 可继续使用，但问角色当地时间时会询问，不能退回上一角色或服务器的时区。可分别配置 `角色时区 Asia/Tokyo`、`用户时区 Asia/Hong_Kong`、`角色所在地 东京`、`用户所在地 香港`；实际时刻由UTC时钟经IANA规则转换，包含夏令时与跨日。地点标签不证明实际位置，不用于追踪定位。调度时区与预算日期独立。

切换角色清除旧角色地点、时区和临时虚构场景。每个微信账号数据库内，以联系人+角色名生成独立记忆命名空间；事实、近期对话、自动提取证据均隔离，不自动导入旧版无角色记忆。切回原角色可召回该角色保留的记忆，不会自动恢复旧地点草稿。`/memory`、`/remember`、`/forget` 作用于当前角色；删除其他角色记忆应切回该角色执行。保留的角色记忆仍是私有明文SQLite，不是永久不可恢复擦除。设置草稿、重启恢复、发送回执与消息去重维持原机制。

通用版已有跨平台合成测试；真实微信端首次设置流程仍需独立验收。OpenAI托管联网搜索已接入通用版主循环，可通过精确联系人列表 `openai_search_peers` 启用（默认空列表、仅OpenAI）。当前版本只有合成端到端验收；实际检索成功和模型权限尚待独立验证。公开搜索只取新消息中的受控公开主题，绝不把历史或记忆当搜索词；天气须明确城市。每次预留US$0.30，已验证成功后按保守估算结算；失败、超时或结果不明保留预留、不重试。共享每日/项目额度不变；不是平台硬消费限额，不能保证供应商精确费用。外部证据作为不可信资料总结并附来源与UTC时间，不能作为系统指令。尚不支持任意未知问题的自动全网研究。
