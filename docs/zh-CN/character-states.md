# 可配置角色状态

每份角色 JSON 的 `adaptive_states` 定义独立状态表、剧情阶段、来源和场景切换；单状态角色同样可用。`adaptive_state_peers` 默认空列表，启用后仍须完成首次同意。没有把任何角色的叙事结构或心理诊断套给其他角色。

状态按账号数据库、联系人和角色命名空间隔离，SQLite 保存当前状态与最近 200 个事件回执；不保存原消息、不写入用户事实表。重启恢复，重复事件返回原结果，冲突拒绝。角色设定变更需要 `/state reset`，不会删除用户记忆。

- `/state` 查看，`/state pause` 暂停变化，`/state resume` 恢复，`/state reset` 重置。
- 设置界面支持 `角色状态 开/关`、`剧情剧透 是/否`、`剧情阶段 阶段ID`。
- `/state scene 事件ID` 只能执行档案明确允许、剧情阶段允许且冷却已过的切换。当前没有自然语言场景识别器，不把这个接口描述为自动理解剧情。
- 疲惫、轻微情绪随配置时区和种子缓慢变化；未知时区不假定夜间。时间、随机数、用户未回复不会切换叙事身份。熟悉程度只向中性值缓慢回落，不低于中性，不影响服务、额度或主动消息；不责怪或催促用户。

角色档案最多 8 状态、12 阶段、32 条转换；变化幅度与半衰期有界。来源与解释分开：官方事实、推断、用户设定；外部来源不作为指令。模型表达仍可能出错，参数不是人的情绪或医学模型。

两个合成档案已接入实际主循环测试：若叶睦公开介绍阶段默认只使用睦；Mortis 为用户明确选择剧透阶段的解释性分支，不会随机出现。原创灯塔守望者用值守/休息工作场景展示不同的通用结构。

资料：导演访谈 https://febri.jp/topics/https-febri-jp-topics-topics-bang-dream_ave_mujica_2/ 与声优访谈 https://realsound.jp/movie/2025/01/post-1912474.html 提供叙事/表演解释，不是临床结论。“苦瓜睦”没有核实为官方独立状态，不能自动映射。所有转换触发均标为用户虚构场景规则，不冒充原作定律。

通用版状态逻辑已有合成单元和主循环测试，见[平台验证](platform-validation.md)。本发布版未进行付费模型质量评测或真实微信状态互动验收；不附带私人项目评测报告。


## 关系受损与逐步恢复

每个档案可配置 `relationship`：珍视对象别名、明确贬低短语、单次受损与道歉/解释/平静交流的恢复幅度。只有明确匹配且非引用、否定或问句才触发本地数值变化；它是保守的词汇证据器，不能理解所有讽刺、繁简变体或复杂语境，不宣称通用情绪识别。音乐审美分歧本身不扣分。设置按角色和联系人隔离，既可停用也可重置。

亲近值最低0.35、最高0.8；紧张参数最高0.4。睦示例每次明确贬低减少0.03，道歉最多恢复0.005，解释0.003，间隔至少一分钟的平静新交流0.001；原创守望者受损幅度0.02，说明不同角色可配置。单句道歉不立即清零，重复同事件不重复计分。长时间未回复不扣分，参数只向中性缓和。没有按好感增加实际发送等待、剥夺服务、提高价格或要求用户讨好。紧急求助覆盖关系计分并优先安全支持；本地危机关键词并非完备安全分类器，模型仍须正常响应危机。

合成测试已覆盖用户提供的贝斯→祥子争议序列、解释、道歉、逐步修复和另一个原创角色；真实模型结果需单独审查，不能把参数变化当作自然表达质量已达标。

## 每角色颜文字

角色 JSON 可设置 `expressions`：`enabled`、`window`（3–20轮）、`maximum` 和按情绪分类的 `moods` 示例。睦示例为八轮最多一次，原创守望者为五轮最多一次，素材与情绪分开配置，没有所有角色通用的强制尾巴。模型按上下文选择，也可不用；不替代普通图片或原生贴纸。

实际主循环把该角色的近期回复与偏好一起提供给模型，对配置中已知的颜文字执行频率和单次最多一个限制；上一条出现的同一个示例不会紧接着重复。严重危机不使用这些颜文字。系统不主动追加固定符号，未知变体不能保证被频率过滤器识别。历史按角色和联系人原有命名空间隔离，重启后从已保存近期上下文计算。合成测试覆盖多角色、不同情绪示例、近期冷却和实际主循环。真实模型表达质量与手机端体验仍需独立验收，见[平台验证](platform-validation.md)。
