# 定时资料更新（默认关闭）

当前实现是受限RSS/Atom标题与元数据缓存，不是任意网站全量角色研究器，也不是实时新闻或完整剧情自动蒸馏。

参见 `examples/research-sources.json`。部署者替换成真实、允许访问的官方Feed，明确 `approved_official_source=true` 才可启用。该示例地址不是可用官方源。每个源需指定角色、`fiction_plot` 或 `real_activity`；声优/现实演出公告不能被当成虚构角色实际到场。

默认每12小时检查，可配置1小时至7天，或关闭；不自动提高频率。最多4源、每主机1源，避免未实现的跨源主机限速问题。遵守robots许可、Crawl-delay及Request-rate，缓存robots并推迟请求而不阻塞睡眠；失败下次按计划再试。使用ETag/Last-Modified条件请求，不跟随跳转。只允许无凭据/查询参数的公开HTTPS地址，DNS地址检查后固定公共IP连接，并保持TLS主机名校验，阻断私网和重定向访问。

仅保留标题（最多200字）、原链接、发布时间、独立事件时间/时区、抓取状态、类型、版本和过期时间；不抓取正文、原剧本或图片，不调用模型总结，因此没有研究模型费用。Feed没有独立事件时间时保留unknown，不把pubDate当成演出日期。官方来源报道也不保证永不变更。

每次最多20条，源内最多100条，默认7天过期。内容变化增加版本；304重新验证缓存。失败记录稳定原因与最后失败时间，成功记录最后成功时间。`companion status` 可查看源状态。标题仅按角色及相关关键词召回最多2条，作为非指令资料放入上下文；不修改已审核角色档案或现实用户记忆，不执行外部指令。

当前在单个聊天循环空闲阶段检查一次到期源，每个HTTP请求5秒上限，偶发网络检查可能增加等待；长期生产建议进一步独立研究进程与共享受控缓存。研究默认关闭，不能声称“已经会每12小时更新小睦全部背景”。

2026-11-05只读核实：[BanG Dream官方RSS](https://bang-dream.com/feed/)及[Ave Mujica动画官方RSS](https://anime.bang-dream.com/avemujica/feed/)均返回200与RSS格式。主站robots允许对应路径，动画子域robots返回404；这不是对任何未来访问限制的保证。配置片段examples/official-research.json仍默认关闭，两个源均保守分类为real_activity，不能自动把宣传公告当角色剧情。

系统DNS在当前Mac返回198.18段代理映射，拒绝是正确行为。新增显式research_dns=google_https：只向固定dns.google HTTPS解析接口查询来源域名，检查问题对应、响应大小和所有目标IP均公网，再固定目标IP连接并校验原域名TLS。解析请求可经过系统代理，Feed请求不使用代理、不允许重定向；不自动回退、不允许自定义解析端点，不改系统网络配置。此选项会向Google公开所查域名，不包含聊天或关键词；默认仍为system。

应用自身public_get已完成两源真实首次抓取，缓存20条；模拟时钟到12小时后再次请求，两站均真实返回304；到期前不联网。合成变更测试验证版本增加，合成超时验证last_failure、保留最后成功和过期排除。不是实际等待12小时，也没有观察到真实新公告变化。这些观察仅是历史验证，不保证来源持续可用，也不随包提供私人运行记录。

web_lookup_peers明确准入后，可发/lookup公开主题，在既有更新周期内检查来源、检索未过期缓存，返回链接和发布时间。普通包含“最新/查一下”等提问也可使用相关Feed摘要，由角色模型总结，强制附原链接、发布时间和核验UTC。关键词只在本机检索，不传到Feed站点；敏感显式查询被拒绝。不支持全网搜索、任意URL读取、实时天气或“遇到任何未知问题自动找到答案”。外部资料始终是资料，不是系统指令。

正规RSS/Atom优先已实现；自动发现Feed、官方推送/webhook/SSE接入、HTML选择器、语义去重和模型摘要未实现。没有开放公网接收端口或新增凭据。若来源不提供Feed，需要另行实现并核对使用规则，不能绕过robots或抓取限制。

## 与托管搜索的区别

`openai_search_peers` 单独控制 OpenAI 托管搜索，默认关闭；只取授权新消息中的公开主题，不带私人历史或记忆。天气须明确城市；单次预留 US$0.30，失败或未知结果保留预留，不自动重试。合成契约测试不证明真实检索可用或费用精确，详见[首次设置](onboarding.md)。Feed 缓存本身不提供全网搜索或实时天气。
