# 功能及平台验收边界

| 功能 | 当前实现 | 未完成/验收限制 |
| --- | --- | --- |
| 三端入口 | Windows cmd/PowerShell、macOS command、Linux sh；本地venv安装和配置菜单 | 需先装Python；微信登录不是零配置；CI只验证核心 |
| 角色/风格 | 可编辑来源档案、剧情时点、性格、状态、颜文字；首次设置与安全词 | 不保证角色质量；不打包版权立绘/剧本；生产定制版质量数据未作为通用版成绩 |
| 模型 | OpenAI/DeepSeek文字接口；OpenAI独立图片key/model/provider边界 | 付费接口本发布版仅合成HTTP契约测试，其他大厂需适配 |
| 图片 | PNG/JPEG/GIF输入，GIF首帧；授权图库普通图；`/image 描述`生成PNG | 通用版未做三端真实微信送达；无自动参考图，无原生贴纸发送 |
| 记忆 | 每联系人/角色隔离，近期持久化，有限明确句式长期事实，查看更正遗忘 | 不是任意自然记忆；每人100条事实；删单项不清除所有历史同义表达 |
| 主动/定时 | daily/random、时区、共享费用/限速、未回复停止后续主动、暂停 | 默认无任务；不保证每任务发出；无心理惩罚/依赖诱导 |
| 关系/多状态 | 可配置角色档案及合成评估 | 不是医学人格诊断；不能声称移植了定制生产全部行为 |
| 联网 | 可配置12小时官方RSS/Atom更新、双时区、受控查询接口 | 非全网实时剧情理解；搜索失败需诚实；来源策略可能拒绝不安全DNS |
| 去重/恢复 | 同一worker锁、持久状态、未知发送不重放 | 停机消息跳过，未知状态需人工审查 |
| 语音/电话 | 本包未实现 | 电话继续搁置，不自动拨号或接听 |

本地及GitHub Actions的具体测试结果记录在 [platform-validation](platform-validation.md)，对应提交的CI日志为进一步证据。不能将Linux/macOS/Windows合成通过称为真实微信全链路通过。
